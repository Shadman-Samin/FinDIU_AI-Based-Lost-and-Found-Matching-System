# Usability Study Status And Protocol

No participant sessions have been conducted by this agent. Automated Firefox
checks validate rendering and interactions, not human usability or task success.

Recruit 3-5 consenting students. Avoid recording names, IDs, credentials or
private proof. Give each a synthetic item scenario, ask them to think aloud, and
record only participant codes, task times, errors, help requests and comments.

Tasks:

1. Switch language and explain which form fields are public versus private.
2. Create a lost report with an optional non-sensitive image.
3. Find analysis status and identify a candidate's score ingredients.
4. Submit the supplied synthetic ownership evidence and find claim progress.
5. Edit a report and explain the finality of archival.

An admin participant reviews a claim and distinguishes approval from physical
handover. Test at least one mobile user and one keyboard-only session. Ask each
participant whether the score proves ownership; an incorrect answer is a blocker
for the explanation copy. Summarize completion rate, median time, observed
problems and actual fixes. Record non-completion honestly; do not replace missing
sessions with automated tests or imagined feedback.
